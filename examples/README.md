# Examples

Real hearsay output, generated by running the tool on two public YouTube
videos. Regenerate with:

```bash
uv run hearsay "https://www.youtube.com/watch?v=rStL7niR7gs" -o examples/rStL7niR7gs.md
uv run hearsay "https://www.youtube.com/watch?v=zjkBMFhNj_g" -o examples/zjkBMFhNj_g.md
```

| File | Video | Shows off |
| --- | --- | --- |
| [`rStL7niR7gs.md`](rStL7niR7gs.md) | CGP Grey — "You Would Be a Terrible Leader" | No chapters → time-based `##` sections; manually-authored captions (`method: captions`) |
| [`zjkBMFhNj_g.md`](zjkBMFhNj_g.md) | Andrej Karpathy — "[1hr Talk] Intro to Large Language Models" | 21 chapters → chapter `##` headings; auto-generated captions (`method: captions-auto`) |

The `ingested` timestamp in the frontmatter changes on each run; everything
else is reproducible.
